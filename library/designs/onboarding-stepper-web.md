# Three-step onboarding with progress rail

*Original Edison X reference pattern. Owner-authored; contains no third-party content. License: owned.*

- **Category:** onboarding
- **Platform:** web
- **Tags:** light, multi-step-form, progress-tracker, minimal
- **Palette:** #ffffff, #f1f5f9, #0ea5e9, #0f172a, #64748b

Centered card walks the user through profile, preferences and invite steps with a left progress rail.

## Structure

- **Layout:** Split screen: narrow left rail listing steps with check states; right side holds the active form card and a bottom action bar.
- **Components:** step rail, form card, text input, choice chips, back and next buttons
- **Typography:** Clean sans, 24px step titles, 14px helper text.
- **Color usage:** White and pale slate surfaces, sky blue for the active step and primary button.
- **Density:** airy

## Build hints

- Allow skipping optional steps
- Save progress after every step
- Show the step count and the time estimate
