# Creator profile with stats and content tabs

*Original Edison X reference pattern. Owner-authored; contains no third-party content. License: owned.*

- **Category:** profile
- **Platform:** web
- **Tags:** light, card-grid, feed, social
- **Palette:** #ffffff, #f3f4f6, #db2777, #111827, #6b7280

Profile header with avatar, bio and follower stats above tabs for posts, collections and about.

## Structure

- **Layout:** Cover band with overlapping avatar; stat row; sticky tab bar; masonry grid of content below.
- **Components:** avatar, stat row, follow button, tab bar, masonry grid
- **Typography:** Bold 28px name, 14px bio, small muted counters.
- **Color usage:** White page, pink accent on the follow button, grey neutrals elsewhere.
- **Density:** balanced

## Build hints

- Keep the follow button visible in the sticky bar
- Use skeleton cards while the grid loads
- Truncate bios with a more link
