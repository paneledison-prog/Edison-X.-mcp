# Search results page with facets and previews

_Original Edison X reference pattern. Owner-authored; contains no third-party content. License: owned._

- **Category:** search
- **Platform:** web
- **Tags:** search, filter-bar, light, data-dense
- **Palette:** #ffffff, #f1f5f9, #2563eb, #0f172a, #64748b

Large search bar, result list with snippets and facets for type and date on the left.

## Structure

- **Layout:** Top search bar with suggestions; left facet column; central result list; optional right preview pane.
- **Components:** search bar, facet group, result row, snippet highlight, preview pane
- **Typography:** 16px result titles in blue, 14px snippets, 12px metadata.
- **Color usage:** White with slate text; highlight snippets with a pale yellow background.
- **Density:** dense

## Build hints

- Show the result count and active filters near the top
- Highlight matched terms in snippets
- Offer a clear empty state with suggestions
