# Weekly meal planner with drag cards

- **Category:** health-fitness
- **Platform:** web
- **Tags:** light, calendar, card-grid, food, drag-and-drop
- **Palette:** #fffaf0, #f4a261, #2a9d8f, #264653, #e9c46a

A seven-column week board where recipe cards are dragged into breakfast, lunch and dinner rows.

## Structure

- **Layout:** Grid of 7 day columns by 3 meal rows; recipe tray docked at the bottom; macro totals pinned in the header.
- **Components:** week grid, recipe card, drag handle, macro bar, tray
- **Typography:** Friendly serif headings with a clean sans for labels.
- **Color usage:** Warm cream background, teal and orange accents for meal types, dark teal text.
- **Density:** dense

## Build hints

- Show macro totals per day under each column header
- Allow keyboard moves for accessibility
- Use a dashed drop zone state for empty slots
