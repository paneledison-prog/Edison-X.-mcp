# Designer portfolio with case study grid

_Original Edison X reference pattern. Owner-authored; contains no third-party content. License: owned._

- **Category:** portfolio
- **Platform:** web
- **Tags:** portfolio, card-grid, minimal, light, editorial
- **Palette:** #fafafa, #ffffff, #111111, #ff4d00, #a3a3a3

Large project tiles with hover reveals leading to image-heavy case studies.

## Structure

- **Layout:** Intro statement at the top; two-column staggered project grid; full-bleed images inside case studies; contact footer.
- **Components:** project tile, hover caption, full-bleed image, text intro, contact footer
- **Typography:** Grotesque sans, 48px intro statement, 14px captions.
- **Color usage:** Neutral greys with one orange accent for hover states.
- **Density:** airy

## Build hints

- Let imagery lead and keep captions short
- Add next and previous project links
- Lazy-load large images
