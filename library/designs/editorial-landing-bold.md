# Editorial landing page with oversized type

_Original Edison X reference pattern. Owner-authored; contains no third-party content. License: owned._

- **Category:** landing-page
- **Platform:** web

- **Palette:** #f4efe6, #111111, #e63946, #2b2b2b, #d8d2c4

Type-led page: a giant serif headline, narrow text columns and a single red accent.

## Structure

- **Layout:** Asymmetric twelve-column layout; headline spans ten columns; body text in a narrow column offset to the right; thin rules between sections.
- **Components:** oversized headline, pull quote, rule divider, text link, footer index
- **Typography:** High-contrast serif at 120px for the headline, 17px book weight body, small caps for labels.
- **Color usage:** Warm paper background, black text, one red accent used for links and marks.
- **Density:** airy

## Build hints

- Let the headline break the grid
- Use thin 1px rules instead of cards
- Reserve the accent color for fewer than five elements
