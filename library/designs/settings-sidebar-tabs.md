# Settings page with grouped sections

_Original Edison X reference pattern. Owner-authored; contains no third-party content. License: owned._

- **Category:** settings
- **Platform:** web
- **Tags:** light, sidebar-navigation, forms, minimal
- **Palette:** #ffffff, #f6f7f9, #0f766e, #1f2937, #9ca3af

Settings split into account, notifications, billing and security with a left list and form panels on the right.

## Structure

- **Layout:** Left vertical section list; right panel with titled cards, each holding labeled controls and a save row.
- **Components:** section list, toggle switch, labeled input, danger zone card, save bar
- **Typography:** 14px labels, 20px card titles, helper text in muted grey.
- **Color usage:** Light grey page, white cards, teal toggles and links, red outline for destructive actions.
- **Density:** balanced

## Build hints

- Save per card instead of a global save
- Place destructive actions in a separate bordered zone
- Use switches only for instant settings
