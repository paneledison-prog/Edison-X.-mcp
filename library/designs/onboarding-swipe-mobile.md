# Swipeable mobile onboarding with illustrations

_Original Edison X reference pattern. Owner-authored; contains no third-party content. License: owned._

- **Category:** onboarding
- **Platform:** android
- **Tags:** mobile, illustrated, carousel, playful, colorful
- **Palette:** #fff7ed, #fb923c, #8b5cf6, #1e1b4b, #fde68a

Three full-screen slides with a spot illustration, a short headline and pager dots.

## Structure

- **Layout:** Full-screen pager; illustration in the top 55%; text block and dots below; pinned primary button and skip link.
- **Components:** pager dots, spot illustration, headline, primary button, skip link
- **Typography:** Rounded display face for headlines, 16px body.
- **Color usage:** Warm peach backgrounds that change per slide, purple used for the button.
- **Density:** airy

## Build hints

- Keep each slide to one idea
- Put the skip link in the top right
- End with a single clear call to action
