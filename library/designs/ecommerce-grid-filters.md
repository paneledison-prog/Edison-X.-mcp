# Storefront product grid with left filters

*Original Edison X reference pattern. Owner-authored; contains no third-party content. License: owned.*

- **Category:** e-commerce
- **Platform:** web
- **Tags:** card-grid, filter-bar, light, retail
- **Palette:** #ffffff, #f8f8f8, #111111, #d4af37, #6b7280

Product listing with collapsible filter groups, sort control and a four-up image grid.

## Structure

- **Layout:** Left filter column at 260px; right grid of four product cards; sort and result count above the grid; pagination below.
- **Components:** filter group, product card, price tag, sort select, pagination
- **Typography:** Neutral sans, 14px product names, 16px bold prices.
- **Color usage:** Mostly white with black text and a gold accent for sale badges.
- **Density:** balanced

## Build hints

- Show active filters as removable chips
- Keep image aspect ratios identical
- Preserve filter state in the URL
